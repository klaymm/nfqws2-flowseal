# Как обновлять сборку

## Как устроено

- `nfqws2-flowseal` - утилита для роутера, в ней вся логика: пакеты, конфиг под роутер, смена стратегии, проверка, уборка, откат, пароль и автообновление.
- `install.sh` - скачивает архив ветки `main` и запускает из него `nfqws2-flowseal install`.
- `nfqws2.conf` - шаблон конфига. На место строки `@STRATEGY@` встаёт выбранная стратегия, `ISP_INTERFACE`, `IPV6_ENABLED` и `CONFIG_VERSION` берутся с роутера.
- `strategies/` - стратегии Flowseal, переведённые на nfqws2, и `index.json` с их описаниями. Их пишет `dev/flowseal2nfqws.py`, как он переводит, описано в [strategies.md](strategies.md).
- `build.conf` - версия сборки и версии пакетов, на которых она проверена.
- `flowseal/` - списки и фейки Flowseal без изменений.
- `web/` - исходники веб-интерфейса (React), `www/` - он же собранный. Роутер берёт `www/` как есть, поэтому после правок в `web/` собранные файлы тоже коммитятся.
- `etc/lighttpd.conf` - веб-сервер на порту 90 для интерфейса.

Роутеры берут сборку из ветки `main`, поэтому туда попадает только проверенное.

## Проверка перед публикацией

С ПК в Git Bash, роутер в той же сети:

```
dev/deploy.sh check   # что изменится на роутере
dev/deploy.sh apply   # поставить рабочую копию
```

Другой роутер: `ROUTER=admin@192.168.2.1 PORT=22 dev/deploy.sh check`.

После установки на роутере проверить, что nfqws2 принимает все стратегии:

```
nfqws2-flowseal strategy --test-all
```

## Новая версия Flowseal

1. Перевести стратегии: `python -I dev/flowseal2nfqws.py --tag 1.10.3` с номером нового релиза. Если скрипт встретил незнакомую опцию, список или фейк, он остановится и скажет, что дописать.
2. Списки из `lists/` положить в `flowseal/lists/` с расширением `.list` и переводом строки в конце, новые фейки из `bin/` в `flowseal/blobs/`. Для нового фейка нужна строка `--blob` в шаблоне и запись в `BLOBS` у скрипта.
3. В `build.conf` поменять `FLOWSEAL_VERSION` и поднять `BUILD_VERSION`.
4. `dev/deploy.sh check`, `dev/deploy.sh apply`, `nfqws2-flowseal strategy --test-all`, проверить голос в Discord и YouTube, потом коммит в `main`.

## Веб-интерфейс

Нужен Node.js 22 или новее. Сборка в папку `www/`:

```
cd web
npm ci
npm run build
```

`npm start` запускает интерфейс на ПК, а запросы к `/index.php` уходят на роутер `192.168.1.1:90`. Серверная часть - `web/public/index.php`: всё, что меняет роутер, она делает через утилиту `nfqws2-flowseal`.

## Новая версия nfqws2-keenetic

1. Прочитать изменения: скрипт запуска (`etc/init.d/common`), конфиг по умолчанию (особенно `CONFIG_VERSION`), Lua-функции, которыми пользуются стратегии.
2. Если нужно, поправить `nfqws2.conf` или утилиту.
3. В `build.conf` записать новую версию пакета и поднять `BUILD_VERSION`.
4. `dev/deploy.sh apply`: утилита сама снимет заморозку, обновит пакет (если в его репозитории лежит ровно эта версия), поставит сборку и заморозит пакет обратно.
5. `nfqws2-flowseal strategy --test-all`, проверить и сделать коммит в `main`.

## Номер версии

`BUILD_VERSION` вида 1.2.3: новая стратегия или возможность - средняя цифра, новые списки и исправления - последняя. `nfqws2-flowseal update` ставит сборку с GitHub, только если её номер больше установленного.
